Base64 Encoder & Decoder

Encode text to Base64 or decode Base64 back to text. UTF-8 safe.

What is Base64?

Base64 is a binary-to-text encoding scheme that represents data using only 64 printable ASCII characters (A-Z, a-z, 0-9, + and /). It is widely used to safely transmit and store binary data in text-based formats — for example, embedding images in HTML or JSON, sending binary data in API payloads, and encoding authentication credentials.

This encoder/decoder fully supports Unicode (UTF-8), so emoji, Chinese characters and other non-ASCII text are handled correctly on both sides.

How to use this tool

  1. Type or paste your text into the Input box.
  2. Click Encode to Base64 to convert text to Base64.
  3. Or paste a Base64 string and click Decode from Base64 to get the original text.
  4. Click Copy Result to copy the output.

Frequently Asked Questions

Why do emoji or Chinese characters get garbled when encoding?

That happens with tools that only handle ASCII. This tool encodes UTF-8 properly, so emoji and non-Latin scripts work correctly.

Can I encode binary files with this tool?

This tool works with text input. For encoding whole files (like images), most people use a dedicated file-to-Base64 converter.

What does the "=" padding at the end of Base64 mean?

"=" characters are padding added so the encoded length is a multiple of 4. They carry no data and can often be removed when the length is already aligned.

Is decoding done locally?

Yes. All encoding and decoding happens in your browser. Nothing is uploaded to any server.
