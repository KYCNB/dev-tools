Hash Generator

Generate MD5, SHA-1, SHA-256, SHA-384 and SHA-512 hashes of any text. Runs locally.

What is a hash?

A hash function takes any input and produces a fixed-length string of characters that uniquely represents that input. The same input always produces the same hash, and even a tiny change in the input completely changes the output.

Hashes are used for password storage, file integrity checks, digital signatures and data deduplication. Note that hashing is one-way: you cannot recover the original text from a hash.

How to use this tool

  1. Type or paste your text into the box.
  2. Choose an algorithm: MD5, SHA-1, SHA-256, SHA-384 or SHA-512.
  3. Click Generate Hash — the result appears instantly, computed locally in your browser.

Frequently Asked Questions

Which algorithm should I use?

For modern applications, prefer SHA-256 or SHA-512. MD5 and SHA-1 are older and have known weaknesses, but are still used for checksums and legacy compatibility.

Can a hash be reversed back to the original text?

No. Hashing is one-way by design. The only way to "find" the input is by brute force or by matching against known values, which is why strong algorithms and salts matter for passwords.

Is my text uploaded to a server?

No. MD5 is computed with pure JavaScript and the SHA family with the browser's built-in crypto API. Everything stays on your device.

Are uppercase and lowercase hashes the same?

The hash value is identical; this tool simply displays it in lowercase hexadecimal. Uppercase is just a different presentation.
