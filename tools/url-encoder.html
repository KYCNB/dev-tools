URL Encoder & Decoder

Percent-encode URLs and query strings, or decode them back to readable text.

What is URL encoding?

URL encoding (percent-encoding) replaces unsafe characters in a URL with a "%" followed by their hexadecimal byte value. For example, a space becomes %20 and Chinese characters become sequences like %E4%B8%AD. This makes URLs safe to transmit and guarantees the browser interprets them the same way everywhere.

It is essential whenever you build query strings, pass parameters in links, or debug API requests that contain special characters.

How to use this tool

  1. Paste a URL, query string, or any text into the Input box.
  2. Click Encode URL to percent-encode it, or Decode URL to reverse it.
  3. Copy the result with Copy Result.

Frequently Asked Questions

Why would I need to encode a URL?

When URLs contain spaces, Unicode characters, or symbols like & and #, they can break or be misinterpreted. Encoding keeps every character safe and unambiguous.

Is this the same as encodeURIComponent?

Yes. This tool uses the same rules as JavaScript's encodeURIComponent/decodeURIComponent, which encodes everything except A-Z, a-z, 0-9, - _ . ! ~ * ' ( ).

Can I decode an encoded URL back to readable text?

Yes, click Decode URL. Most modern URLs encode UTF-8, and this tool decodes that back into the original readable characters.

Is my URL sent anywhere?

No. Encoding and decoding happen entirely in your browser, locally.
